## SAS Visual Analytics Dashboards

This project includes two interactive dashboards developed using SAS Visual Analytics (SAS Viya).

### Dashboard 1 – GPU Energy Prediction
- Actual vs predicted GPU energy consumption
- Prediction error distribution
- Average prediction error by energy range

### Dashboard 2 – Carbon Emission Intelligence
- Actual and predicted carbon emissions
- Model performance comparison (RMSE)
- Predicted carbon emissions by workload status

**Dashboard report:** `visualizations/CarbonIQ_Dashboard.pdf`
